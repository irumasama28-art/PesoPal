## 🛠️ IF SOMETHING GOES WRONG

**Workflow failed?**
- Check Actions tab error message
- See RELEASE_GUIDE.md troubleshooting
- Can manually release if needed

**APK not created?**
- Check build logs for compiler errors
- Verify keystore secrets configured
- Try re-pushing tag

**latest.json not updated?**
- Check gh-pages branch exists
- Verify workflow completed
- Check GITHUB_TOKEN permissions

**Users can't update?**
- Verify latest.json is valid JSON
- Check versionCode increased
- Test on actual device
